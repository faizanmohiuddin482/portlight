# Portlight

**Who's on port 3000?** A native macOS menu bar app for your ports — and for keeping your Mac awake while they work.

> Work in progress. Not ready to install yet.

## Build from source

Requires macOS 14+ and the Xcode Command Line Tools (`xcode-select --install`).

```sh
scripts/make-app.sh && open build/Portlight.app
scripts/test.sh   # run the tests
```
